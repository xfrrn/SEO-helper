# SEO Helper

Chrome / Edge 侧边栏插件，按平台组织不同网页功能。目前支持 `sem.3ue.co` 的关键词魔法工具；打开侧栏后，在 SEM 下选择「词根研究」。功能页顶部「全部功能」返回入口，任务运行或保存期间禁用切换。

## 项目结构与扩展

```text
manifest.json                      # 扩展权限、后台和侧栏入口
src/
  app/                             # 扩展外壳，不包含网站业务逻辑
    background.js
    sidepanel.html / .js / .css     # 按平台展示功能入口
  platforms/
    index.js                       # 平台与功能的导航登记表
    sem/
      keyword-magic/               # SEM → 关键词魔法工具
        sidepanel.html / .js / .css # 此功能独立的界面、状态和任务流程
        core.js                    # SEM 查询、词根批次、预览数据处理
        collector.js               # 此网页的 DOM 采集与状态校验
        native-export.js           # 此网页的导出交互与下载匹配
        root-library.js            # 此功能的预制词根
tests/
  structure.test.js                # 入口、登记表和页面资源检查
  core.test.js                     # SEM 功能回归
  browser.mjs                      # 入口导航与 SEM 浏览器集成检查
```

新增功能：

1. 在 `src/platforms/<平台>/<功能>/` 创建独立的 `sidepanel.html` 及需要的 JS/CSS；同一平台的新网页功能放在相邻功能目录。
2. 在 `src/platforms/index.js` 对应平台的 `features` 中登记 `id`、`name`、`description`、`page`；新平台增加一项。`page` 使用从扩展根目录开始的路径，入口自动展示，无需修改其他功能。
3. 新功能使用独立的存储键，例如 `seoHelper:bing:site-audit`。现有 SEM 词根研究继续独占旧键 `seoHelper`，保留用户模板、词库和导出进度，无需迁移。
4. 新网站域名加入 `manifest.json` 的 `optional_host_permissions`，由对应功能在用户操作时申请所需权限；只为已实现功能声明权限。
5. 功能页提供返回 `src/app/sidepanel.html` 的入口；切换前保存输入，运行任务期间阻止切换。补充功能测试，运行 `npm test`，涉及页面交互时再运行浏览器检查。

依赖方向：入口只读取导航信息，不加载功能业务模块；功能之间不互相导入。网站选择器、URL 规则、权限申请和下载识别归对应功能所有。同平台确有复用时再提取到平台目录；跨平台确有复用时再增加 `src/shared/`。不要让其他平台依赖 SEM 的 `core.js`，也不要直接整份复制 SEM 流程来接入业务不同的网站。继续使用原生 ES Modules，无构建步骤、无新增运行时依赖。

界面正文和按钮 16px、词根 17px、辅助文字至少 14px。窄侧栏内自动换行，展开导出设置时可独立滚动。

**v0.8 内置 51 个工具类词根，可搜索、勾选加入研究，并自行添加或删除词库条目。** 支持命名保存筛选模板，下次从下拉框选择即可复用数据库和筛选条件。词根每行一批，行内用逗号分隔，点击一行即可选择本批；支持上一批 / 下一批及指定下载子文件夹。下载使用网站右上角的原生导出：选择「所有」，点击 XLSX / CSV / CSV Semicolon，保留网站文件的原始内容。每个词根下载一个文件，可直接交给 Agent 分析。沿用网站文件名，重名时自动加编号，不覆盖已有文件。

## 安装与更新

无需 npm install 或构建。Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，打开「开发者模式」，点击「加载已解压的扩展程序」，选择本仓库目录 `D:\codes\SEO\SEO-Helper` 或安装包解压后的目录。

已安装旧版：替换文件，在扩展管理页点击 SEO Helper 的刷新按钮，再关闭并重新打开侧边栏。首次原生导出会申请下载权限，用于确认网站文件已下载完成。需要 Chrome 116+ 或支持 Side Panel 的新版 Edge。

## 使用

1. 在浏览器登录 SEM，打开关键词魔法工具，设置所需数据库及筛选条件。
2. 从「筛选模板」选择已保存的方案，或展开「编辑 / 保存筛选」并点击「读取当前页面链接」，也可粘贴完整链接。插件保留筛选参数，只替换词根 `q` 并清除分页 `page`。内置初始筛选来自最早提供的链接；更改网站条件后请重新读取链接。
3. 展开「从词根库选择」，勾选词根并点击「加入待研究」，每 5 个自动组成一批。也可展开「批量粘贴 / 编辑词根」，每行输入一批，行内用逗号分隔词根，点击「完成编辑」。例如第一行 `checker, calculator, converter`、第二行 `translator, ai writer`，列表会显示两批，分别包含 3 个和 2 个词根。`ai writer` 等含空格的词组保持完整。
4. 点击列表中的一行，高亮选择本批。展开底部「导出设置」，选择格式及子文件夹，再点击「导出本批」。插件复用一个研究标签页，按该行内的词根逐个点击网站原生导出，选中词表范围「所有」并点击指定格式。文件下载完成或确认当前筛选下无结果后，继续下一个词根，不必先运行预览。完成后可点击「下一批」。
5. 要导出目前浏览器页面的词表，点击「原生导出当前页」。此操作使用当前网页的查询和筛选，不重新导航。也可展开某个词根，单独点击「原生导出」。
6. 要同时浏览本批结果，点击「打开本批」。下方「本批词根结果」仍可展开某个词根，单独打开、读取预览或再次导出。预览只覆盖已加载行，原生导出文件由网站生成。

网站菜单包含「所有 / 此分组 / 已选定」和三种格式；插件选「所有」，保持网站已有的「保持分组」设置。格式和范围依据提供的实际菜单截图，[Semrush 官方说明](https://www.semrush.com/kb/617-keyword-magic-tool-manual)也介绍了该导出入口。实际行数和可用格式受网站当前筛选与账号导出额度影响。

## 筛选模板

1. 在 SEM 设置好条件，展开「编辑 / 保存筛选」，读取当前页面链接或粘贴完整链接。
2. 填写模板名称（例如 `美国 · 高搜索量低难度`），点击「保存模板」。可保存多个模板，名称最长 60 个字符。
3. 下次在上方「筛选模板」下拉框选择即可应用，下方显示当前数据库和筛选摘要。重开侧栏会恢复上次使用的模板及条件。

模板保存链接中的数据库、匹配方式和完整筛选参数；任务会继续使用当前批次的词根，下载格式和文件夹沿用当前设置。分页和临时网关参数不写入模板。

选择模板后更改链接，原模板不会自动覆盖。保留原名称时按钮显示「更新模板」，点击才会更新；换一个名称则保存为新模板。名称不区分大小写。旁边「删除」按钮移除选中模板，当前已应用的筛选仍可继续使用。

模板保存在当前浏览器的 `chrome.storage.local`，重启浏览器仍保留；不自动跨设备同步，卸载扩展会删除。切换模板不访问网站，之后打开或导出本批时使用选中的条件。

## 预制与自定义词根库

- 内置用户提供的 **51 个词根**，按原表顺序保留中文含义及常见搭配。`Sender / Receiver`、`Sample / Template`、`Scheme / Pattern`、`Checker / Detector` 已拆为独立词根；`Convert` 和 `Converter` 分别保留。
- 搜索可匹配英文词根、中文含义或搭配。可以跨搜索结果勾选；「全选结果」勾选当前匹配项，「取消选择」清除所有勾选。
- 「加入待研究」按词库顺序追加选中的词根，每 5 个一批，末尾不足 5 个独立成批，并跳过已在待研究列表中的同名词根。空列表加入全部预制词根会生成 **11 批**。待研究列表总计最多 200 个词根。
- 在「添加自己的词根」中输入词根，多个用逗号分隔，点击「添加」。同名词根不重复加入，含空格的词组保持完整；新增条目自动勾选，可继续加入研究。
- 每条旁边的「删除」移除词库条目，预制和自定义词根都可删除。它不移除已经加入待研究的批次；研究列表可在「批量粘贴 / 编辑词根」中修改。
- 词库保存在本机；重开后保留自定义条目及删除结果。升级旧版时初始化预制词库，已有筛选模板和研究批次继续使用。删除所有词库条目后不会自动重新填入预制数据。

## 每行一批

- 编号从 **1** 开始，每行是独立的一批。行内支持中英文逗号或分号，自动去重；空行忽略，总计最多 200 个词根，每个词根最长 150 个字符。
- 默认选择第一批；点击行文字或「上一批 / 下一批」切换，当前批次会保存在本机。按钮只打开或导出高亮行内的词根。
- 「打开本批」为该行每个词根新建一个后台 SEM 标签页，沿用相同筛选条件。导出仍是每个词根一个网站原生文件。
- 每行右侧显示已处理数量 / 本批词根数，包含成功下载和已确认无结果的词根；存在空结果时单独标注数量。下方结果区分别统计「已导出」与「无结果」。不同批次进度独立，即使两批含相同词根，也可分别处理。单个词根的「原生导出」可重复检查或下载。
- 升级旧版会保留原有换行、筛选、下载设置及对应记录；旧版曾将逗号转成换行的数据，可在编辑框内重新合并为想要的批次。

## 编辑和替换批次

在「批量粘贴 / 编辑词根」中直接增加、删除或替换行。删除一行会清理对应的插件记录；改变某行的词根内容会作为新批次处理，只调整不同行的顺序则保留进度。清空编辑框并完成编辑，可清空整张列表，再粘贴新的批次。已下载文件始终保留。

运行任务时不能编辑或切换批次；底部「导出本批」会变为「停止任务」，点击即可停止后续工作。保存失败时保留上次列表和记录，在底部显示错误。

## 指定保存文件夹

- 在「导出子文件夹」填写 `SEO-Helper/项目A`，文件会自动保存在 **浏览器下载目录 / SEO-Helper / 项目A**，缺少的子文件夹自动创建。支持中文、空格、多层目录及 Windows 反斜杠；留空则直接保存到浏览器下载目录。
- 要直接保存到 `D:\SEO` 等完整磁盘路径，点击插件的「更改下载位置」，在浏览器下载设置中把「位置」改为 `D:\SEO`，然后将插件「导出子文件夹」留空。若填写 `项目A`，则保存到 `D:\SEO\项目A`。浏览器下载位置是全局设置，会影响其他网站下载。
- 若希望每次弹窗选位置，在同一个浏览器设置页开启「下载前询问每个文件的保存位置」。批量导出会等待你完成保存，每个文件最多等待 120 秒；最终以浏览器保存对话框中的位置为准。
- 文件夹设置会自动记住；导出后展开词根，可看到实际保存路径并点击「打开所在文件夹」。更改子文件夹后再次批量导出，会重新下载到新目录，不会因旧目录已有记录而跳过。

Chrome 的原生下载接口只允许建议下载目录内的相对路径，不能直接传入 `D:\SEO` 或 `..`。插件通过 `onDeterminingFilename` 给本次 SEM 原生文件指定子目录，不读取、重建或再次请求文件内容；其他网站下载不受插件的子文件夹设置影响。参见 [Chrome 下载路径规则](https://developer.chrome.com/docs/extensions/reference/api/downloads#type-FilenameSuggestion)。如果保存对话框或其他下载扩展改变了位置，请以结果中显示的实际路径为准。

## 任务与文件

- **v0.8.1：无结果时自动继续。** 页面明确显示「未找到任何数据」等空结果提示，且筛选提示或零数量能佐证时，插件等待页面状态稳定后标记「无结果」，跳过下载并继续下一词根。整批都无结果也会正常结束，不生成空文件，不修改网站筛选条件。原生导出当前页和单词预览也支持空结果。
- 无结果记录随当前批次与查询条件保存在本机，重开侧栏或再次导出本批会跳过已确认的空结果；改变筛选条件会重新检查。改变格式或文件夹不会重查空结果。要在相同条件下刷新，展开该词根点击「原生导出」；若新预览读到数据，旧的无结果导出标记也会清除。
- 禁用的导出按钮、空白表格、侧边分组无结果或页面加载中，均不会单独当作无结果。登录、验证、加载异常或未知页面仍会报错或等待超时，保留重试机会。页面稳定依赖 DOM 提示和等待时间；网站改版或长时间未显示加载标记时，可能需要人工复核。
- 任务运行时保持侧边栏打开，不要更改研究标签页的查询。批量导出串行执行；请勿在其他 SEM 标签页同时导出，以免同源下载无法区分。
- 已完成的文件由浏览器保存。插件记录词根、来源链接、格式、子文件夹、实际文件路径和下载完成时间，不修改、合并或重新生成文件内容。
- 同一批内再次点击「导出本批」，会跳过当前筛选、格式和子文件夹下已成功的词根。要重新下载，展开对应词根点击「原生导出」，或删除该行并完成编辑后再添加。改变浏览器的全局下载位置不会自动重置插件已有的导出记录。
- 点击停止或关闭侧边栏会停止后续任务；浏览器已经开始的下载可能继续。重新运行前先检查下载记录，避免重复文件。
- 网站导出菜单不可用、无法确认「所有」、下载中断或未确认完成时，会停止并给出说明。每次下载最多等待 120 秒；若出现浏览器保存对话框，需要完成保存。不要把超时提示当作文件一定没下载。
- 浏览器若询问是否允许该网站下载多个文件，需要先在浏览器中允许，批量下载才能继续。
- 原生导出独立于预览表格识别；即使页面表格结构暂时无法解析，只要原生导出控件可识别，仍可导出。若只有图标且无法定位按钮，可以先在网页手动打开「导出数据」菜单，再用「原生导出当前页」。

## 权限与存储

使用 `sidePanel`、`storage`、`activeTab`、`scripting`，按需申请 `https://sem.3ue.co/*` 及 `downloads`。下载监听仅在导出任务期间工作，筛选点击后产生、来源为 SEM 且格式匹配的新下载，为该文件设置子目录并读取完成状态。点击「打开所在文件夹」时只查询对应的下载 ID，不扫描已有下载历史。Chrome 下载事件没有来源标签页 ID，因此使用串行任务、来源、格式和可用的 referrer 查询信息进行匹配。请只在一个侧边栏运行导出任务。

没有服务器、AI API、Cookie 读取、遥测或自动上传。配置、筛选模板、词根库、预览和导出进度保存在 `chrome.storage.local`。临时网关参数 `__gmitm` 不保存在研究链接中；请使用浏览器的正常登录状态。卸载会删除插件本机进度、模板和词库，已下载文件不受影响。
