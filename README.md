# SEO Helper

Chrome / Edge 侧边栏插件，按平台组织不同网页功能。目前支持 Google Trends 新版「分组对比」「词义分析」、SEM / SIM「词根研究」，以及 GameMonetize「游戏采集」。功能页顶部「全部功能」返回入口，任务运行或保存期间禁用切换。

v0.10.1 首页按平台显示一张卡片，Google Trends 的「分组对比」「词义分析」放在同一卡片内。SEM 与 SIM 初始词根库使用相同的 51 个词，但各自保存模板、词根编辑、批次和采集结果。

## GameMonetize 游戏采集（v0.12.2）

1. 在扩展管理页刷新 SEO Helper，关闭并重新打开侧栏，在首页选择 **GameMonetize · 游戏采集**。
2. 选择「当前页面」，浏览器切换到 `https://gamemonetize.com/` 下的游戏详情页，点击「采集当前游戏」。首次操作申请此域名的访问权限。
3. 侧栏显示游戏标题、ID、手机支持状态、采集时间及完整 XML。`Mobile Ready : Yes` 显示「支持（Yes）」、`No` 显示「不支持（No）」；缺少标记显示「未标注」，未知标记会报错。这是网站声明，未执行手机实机兼容测试。
4. 「复制全部信息」复制 JSON，包含 `gameId`、`title`、`pageUrl`、`mobileReady`（`true` / `false` / `null`）、`xml`、`capturedAt`；「复制 XML」单独复制原始 XML；「下载 XML」保存为 `gamemonetize-游戏ID.xml`，手机支持状态不写入网站原始 XML。

批量采集与植入资料包：

1. 选择「批量链接」，每行粘贴一个 `https://gamemonetize.com/` 游戏详情页链接，点击「开始批量采集」。输入框下实时显示不重复的有效链接数量，同时显示重复和无效行数。粘贴、拖入文本、离开输入框及开始采集时自动整理重复项；手动输入过程中保留原文和光标。最多 200 个不同链接，忽略空行和链接的 `#` 片段，按输入顺序去重，保留查询参数；无效行原文保留供修正，不会被静默丢弃。
2. 插件按顺序请求页面 HTML，再读取该游戏的 XML，复用单页采集的标记解析和 RSS / ID 校验。无需预先打开这些网页，也不创建研究标签页；网页脚本不执行。每项显示成功、失败原因和手机支持状态，某项失败后继续后续链接。
3. 「停止采集」取消当前请求或等待，保留已完成项；链接列表未变时可「继续未完成项」，已成功和已失败的项不重复采集。「重试失败项」只将失败项重新排队，同时继续原有未完成项，已成功的 XML 保留且不重新请求；适用于旧版本留下的限流失败记录。完成后的「重新采集全部」或更改链接列表后开始新批次，会替换插件中的本批结果。每项完成后保存进度；切换模式或返回全部功能时也保存输入。重开恢复记录但不自动发起请求。
4. 至少成功一个游戏后可「下载 ZIP」。下载包包含 `xml/序号-游戏ID.xml`（逐份保留网站 XML 原文）和 `manifest.json`。清单记录导出时间、总数、成功 / 失败 / 未完成数量，以及各输入链接的 `status`；成功项包含 `gameId`、`title`、最终 `pageUrl`、`mobileReady`、`capturedAt`、对应的 `xmlFile`，失败项包含 `error`。同一游戏的不同链接也使用不同序号，文件不会互相覆盖。失败和未完成项不生成替代 XML。

编辑链接后，下方仍保留上次批次结果，下载按钮会显示「下载上次 ZIP」；点击「开始新批次」后才替换结果。

批量游戏请求至少间隔 3 秒；页面或 XML 返回 HTTP 429 时，优先遵守 `Retry-After` 的秒数或 HTTP 日期，未提供有效值时依次等待 60 / 120 秒，最多自动重试两次。等待倒计时显示在采集按钮下方，可随时停止；等待不占用单次请求的 15 秒超时，同一侧栏停止后继续也会遵守剩余冷却时间。持续限流会暂停批次，当前及后续项保持未完成，已成功结果可下载；不会继续把剩余链接逐个记为失败。站点限额没有公开保证，不能保证任何采集速度都不会触发限流。

「添加当前网页链接」读取当前窗口活动标签页的 GameMonetize 链接并追加到输入框，已有链接不会再次插入，数量立即更新并保存。不打开其他标签页或开始采集；其他网站或正在跳转的页面会提示后保持原列表。达到 200 个时仍可识别已有链接，新增第 201 个会被拒绝。

采集期间保持侧栏打开；关闭或刷新后可重开并继续未完成项。批次存储在独立键 `seoHelper:gamemonetize:batch`，不覆盖单页结果和其他平台数据。保存失败会停止本次任务并明确提示，内存中的成功结果仍可下载。ZIP 使用标准无压缩封装，不增加运行时依赖，也不申请额外下载权限。

单页采集读取当前窗口的活动标签页，从 `.product-feed` 中的 `XML-游戏ID` 按钮取得 ID，再在该页面请求同源 `/feed.php?format=1&id=游戏ID`。批量采集在扩展中直接请求允许域名的 HTML / XML，携带浏览器允许发送的站点凭据，拒绝跳转到其他网站的页面。该 XML 地址已依据网站实际按钮脚本和真实响应核对。保留响应原文，校验 RSS 结构和单个游戏 ID；HTTP 错误、HTML 验证页面、损坏 XML、ID 不符和超时均显示错误，不生成替代数据。单页另检查采集期间页面切换；页面 HTML 和 XML 请求各自最多等待 15 秒。

单页仅保留上次成功保存的采集结果，独立存储于 `seoHelper:gamemonetize:game`；重开只恢复显示，不自动请求网站。重新采集开始时清空界面中的旧结果，失败不覆盖已保存记录；保存失败会保留本次界面结果并明确提示，可继续复制或下载。采集、复制和保存期间禁用功能切换。文件下载使用浏览器原生链接。

## SIM 词根研究（v0.10.0）

刷新扩展并重开侧栏，在首页选择 **SIM · 词根研究**。对应 `https://sim.3ue.co/#/digitalsuite/acquisition/findkeywords/keyword-generator-tool/`，默认使用提供的 Google / 全球 / 最近 28 天 / 语句匹配 / 搜索量 ≥ 30,000 / KD 1–30 链接。

- 与 SEM 共用词根库、筛选模板和批次界面：内置 51 个词根，可搜索、勾选、增删；每 5 词导入一批，也可直接粘贴，每行一批。
- 在 SIM 网页设置筛选后，点击「读取当前页面链接」或粘贴完整链接，可命名保存模板。切换词根只替换 hash 查询中的 `keyword` 并清除分页；保留地区、时间、搜索引擎、流量来源、匹配类型及其他筛选参数。
- 「打开本批」为该批每个词根打开网站结果页；展开单个词根可「打开结果」或「读取预览」。底部「读取本批预览」按序读取已加载的关键词表格，可停止；预览区分期间搜索量与平均搜索量，不代表网站全部结果。
- 读取预览首次申请 SIM 页面权限。没有导出按钮、下载设置或 SIM 下载逻辑，不申请下载权限。原有 SEM 下载功能继续保留。
- 进度跨天保留。「清除本批记录」可重读当前筛选下的本批，「清空待研究」清空批次和预览，保留模板及词根库。SIM 独立存储在 `seoHelper:sim:keyword-generator`，不读写 SEM 或 Trends 进度。

SIM 使用 hash 路由。预览复用标签页时会重新加载，以避免采集前一个词根的表格；加载、登录、验证或未知结构不会误记为无结果。仅在识别到关键词表格、零数量及明确空结果提示时记录无结果。页面读取适配标准表格、ARIA 表格及 swReactTable；实际网站的 DOM 兼容性仍需登录后确认。本次工具浏览器被重定向到登录过期页面，未完成真实账号下的预览验证；分批链接与界面流程用隔离模拟页面验证。

## Google Trends 分组对比（v0.9.0）

1. 刷新扩展、重新打开侧栏，在首页进入 **Google Trends · 分组对比**。
2. 浏览器打开并登录 [Google Trends 新版探索](https://trends.google.com/explore?q=Translator&date=today%201-m)。Google Trends 域名权限随插件安装声明；网页翻译与快捷按钮自动运行，不需要先打开侧栏或启动功能。
3. 选择时间和地区，默认「过去一个月 / 全球」。时间选项与截图一致：过去 1 小时、4 小时、24 小时、一周、一个月、3 个月、1 年、5 年、2004 年至今、当年、上一年（当前为 2026 年和 2025 年），以及自定义。年份对应该年 1 月 1 日至 12 月 31 日；自定义选择起止日期后点击「应用日期」，最早从 2004 年开始，支持同一天，拒绝无效或倒序日期。也可点击「读取当前 Trends 时间与地区」，沿用页面上的时间和地区（包括自定义日期及地区代码）。
4. 点击任意一行，把这组词一次性填入对比。优先更新当前窗口内正在使用的 Trends 标签页，否则复用窗口内已有的 Trends 标签页；没有时才新建。每次替换整组词，网站会重新加载对比结果。
5. 默认使用 51 个预制词根，每 5 词一组，共 11 组。展开「编辑分组」可新增、修改、删除；每行一组，支持中英文逗号或分号，含空格的词组保持完整。保存后才可点击修改过的词组；空列表会被保留，不会自动恢复默认词组。

**仅生成 `https://trends.google.com/explore?...`，不会生成旧版 `/trends/explore` 地址，也不会点击网站的「继续使用传统版」。** 使用网页原生 `q` 参数加载对比，没有模拟逐项输入或调用私有数据接口。新版需要可用的 Google 登录状态；若网站要求登录，请在网页完成，插件不会自动切换旧版。

每组最多 8 个词，总计最多 200 个，每词最长 150 字符，组内忽略大小写去重。新版 8 个对比项的上限参见 [Google Trends 官方说明](https://support.google.com/trends/answer/4359550?hl=en)。词中 `+` 等 Google 搜索运算符仍由网站按其搜索语义处理。

时间、地区由侧栏设置；复用页面时保留当前 `cat`（类别）、`gprop`（搜索类型）和 `hl`（语言）。其他参数及旧词组不复制，未打开 Trends 时按网站默认类别和搜索类型。词组、选中行、时间和地区单独保存到 `seoHelper:google-trends:compare`，不修改 SEM 的词库、模板和导出记录。

## 词义分析

在首页打开 **Google Trends · 词义分析**，也可从分组对比页顶部切换。尚无结果时显示一行 36px 高的关键词输入与「分析」按钮；输入一个词或短语，点击「分析」或按 Enter。显示结果后隐藏整行输入，只保留紧凑导航、来源切换、重试和跳转，结果填满剩余高度。输入最长 150 字符，空格词组保持完整；多词对比请使用「分组对比」。

| 入口 | 查询内容 |
| --- | --- |
| Google | 内嵌 Google 搜索，查询当前关键词 |
| Time | Google Trends 时间趋势图 |
| Geo | Google Trends 地区热度图 |
| Bing | 内嵌 Bing 搜索 |
| Domains | [Instant Domain Search](https://instantdomainsearch.com/) 域名查询，带入关键词 |
| Ahrefs | [免费关键词工具](https://ahrefs.com/keyword-generator)，复制关键词后跳转并粘贴查询 |

Time / Geo 读取分组对比中保存的时间和地区，未设置时为过去一个月、全球。图表使用 Google 提供的专用嵌入页（`/trends/embed/explore/`），「跳转」始终打开新版 `/explore`。图表自身指向传统探索页的弹窗链接被禁止，使用侧栏的「跳转」即可打开新版。图表嵌入方式参见 [Google 官方说明](https://support.google.com/trends/answer/4365538?hl=en)。

Google、Bing、域名和趋势图在侧栏加载；遇到网站登录、验证、网络问题或不允许内嵌时，可点击「重试」或「跳转」。Ahrefs 禁止内嵌，也没有经过验证的关键词预填链接，因此提供「复制关键词」与「跳转」，不显示空白内嵌页。没有移除网站的安全响应头或绕过登录、验证。

只加载当前选中的来源，不同时向六个网站提交关键词。上次输入和来源保存在独立键 `seoHelper:google-trends:analysis`；重新打开仅恢复输入，点击「分析」后才发送查询。切换功能会保存输入，保存失败时保留编辑内容并提示。读取分组对比的时间、地区不会改写分组或 SEM 数据。此功能展示第三方网页结果，不生成 AI 释义或调用 AI API。

第三方页面自己的搜索框可直接改词；跨域隔离使插件不能读取其内部改词，切换来源仍使用最近一次由插件接收的关键词。再次从 Trends 点击「分析」会更新关键词。

## Trends 网页快捷按钮与中文翻译（v0.13.3）

1. 网页翻译与快捷操作始终自动启用，没有启动按钮、总开关或翻译开关；不需要打开侧栏或先保存设置。安装后访问探索页自动加载，扩展启动时也会同步已有探索页。旧版本保存的 `enabled=false` / `translate=false` 不再阻止功能，已有基准词保留。「词义分析 → 设置」只编辑基准词。更新插件后，在扩展管理页重新加载 SEO Helper（版本应为 `0.13.3`）并刷新原 Trends 标签页，清除旧版本注入脚本；不需要再启用功能。`trends.google.com` 与 `translate.googleapis.com` 已移入安装时的 `host_permissions`，浏览器若提示更新权限，仍须完成浏览器自身的权限确认；其他平台保持按需授权。
2. 在新版热门／上升查询或传统版相关查询上悬浮、键盘聚焦，出现「复制／对比／分析」。新版按查询表格的第二列读取关键词，不把第一列排名当成关键词，也不要求存在探索链接；排除主题表格。鼠标可从查询行移到浮动按钮，翻页或复用行时更新原词和译文。复制仅复制原始关键词；对比带入两个已保存基准词和当前词，按大小写不敏感去重，保留来源页面的时间、地区、类别、搜索类型和语言，始终打开新版 `/explore`。每个窗口使用独立结果标签页并复用，原查询列表保留；结果页关闭或已离开探索页时新建。
3. 两个基准词默认 `happy birthday images`、`GPTs`，可在设置中修改；每个 1–150 字符、不能为空或重复。设置使用独立键 `seoHelper:google-trends:page-actions`，不改变已有分组和筛选设置。
4. 点击「分析」直接在当前标签页专属的原生侧栏中查询 Google；临时请求按窗口隔离，仅消费一次，普通重开不自动重查。其他侧栏正在采集、导出或保存时明确提示等待，避免中断任务。可以用 Esc 关闭快捷按钮，Tab 从查询进入按钮组。
5. 自动将外文译为中文，显示在原关键词下方；复制和查询继续使用原文。与本机安装的 TrendsBar 0.5.1 相同，调用 Google 在线翻译地址 `https://translate.googleapis.com/translate_a/single`，自动识别来源语言并译为简体中文，无需 API Key、浏览器 Translator API 或本地模型。首页与设置明确说明会把当前显示的外文关键词发送给 Google，不发送整页、Trends 筛选或账号凭据。请求只在扩展后台发出，校验顶层探索页来源、权限和关键词，固定服务地址，不接受网页提供的任意 URL；15 秒超时，合并完整译文分段，HTTP / 网络 / 格式错误明确显示并提供「重试翻译」，失败后不自动循环请求。浏览器撤销翻译服务访问权限时保留三个按钮，提示到扩展管理页恢复权限；撤销 Trends 权限会清理按钮与译文，恢复权限后自动重新加载。此免 Key 网页接口没有公开稳定性承诺，可能限流或变化；不把失败伪装为译文。

中文、主题项、嵌入图表不翻译；当前处理含拉丁字母且不含中文的查询，由 Google 识别来源语言并译为中文。译文仅为机器辅助理解，不代表对人名、品牌或新词含义的人工确认。翻译结果在本页内复用，不保存网页查询历史。

Trends 通过 `history.pushState` / `replaceState` 从首页进入探索或调整关键词、筛选时，Chrome 消息中的 `sender.url` 仍可能是文档初始地址。后台仅用它校验 Google Trends 来源，以浏览器提供的 `sender.tab.url` 判断当前探索路由和读取筛选；不要求两者逐字相等。顶层 frame、标签页 / 窗口 ID、非活动文档和真正待完成的跳转仍会校验，不读取网页自报的来源 URL。翻译、对比、分析复用同一个校验，保持首击打开原生侧栏所需的同步调用。

新增功能：

1. 在 `src/platforms/<平台>/<功能>/` 创建独立的 `sidepanel.html` 及需要的 JS/CSS；同一平台的新网页功能放在相邻功能目录。
2. 在 `src/platforms/index.js` 对应平台的 `features` 中登记 `id`、`name`、`description`、`page`；新平台增加一项。`page` 使用从扩展根目录开始的路径，入口自动展示，无需修改其他功能。
3. 新功能使用独立的存储键，例如 `seoHelper:bing:site-audit`。现有 SEM 词根研究继续独占旧键 `seoHelper`，保留用户模板、词库和导出进度，无需迁移。
4. 新网站域名加入 `manifest.json` 的 `optional_host_permissions`，由对应功能在用户操作时申请所需权限；只为已实现功能声明权限。用户明确要求始终自动运行的 Trends 网页增强及 Google 在线翻译使用 `host_permissions`，不增加手动启动步骤。
5. 功能页提供返回 `src/app/sidepanel.html` 的入口；切换前保存输入，运行任务期间阻止切换。补充功能测试，运行 `npm test`，涉及页面交互时再运行浏览器检查。

依赖方向：入口只读取导航信息，不加载功能业务模块；功能之间不互相导入。网站选择器、URL 规则、权限申请和下载识别归对应功能所有。同平台确有复用时再提取到平台目录；跨平台的预制词根放在 `src/shared/`，各功能保存的编辑记录仍独立。不要让其他平台依赖 SEM 的 `core.js`，也不要直接整份复制 SEM 流程来接入业务不同的网站。继续使用原生 ES Modules，无构建步骤、无新增运行时依赖。

界面正文和按钮 16px、词根 17px、辅助文字至少 14px。窄侧栏内自动换行，展开导出设置时可独立滚动。

SEM / SIM 的词根研究由 `src/shared/research-panel.js` 复用状态和界面流程；平台提供自身 URL、预览解析与采集函数。SIM 不加载 SEM 的原生导出模块；两者保存的模板、词根库和进度独立。

**v0.8 内置 51 个工具类词根，可搜索、勾选加入研究，并自行添加或删除词库条目。** 支持命名保存筛选模板，下次从下拉框选择即可复用数据库和筛选条件。词根每行一批，行内用逗号分隔，点击一行即可选择本批；支持上一批 / 下一批及指定下载子文件夹。下载使用网站右上角的原生导出：选择「所有」，点击 XLSX / CSV / CSV Semicolon，保留网站文件的原始内容。每个词根下载一个文件，可直接交给 Agent 分析。沿用网站文件名，重名时自动加编号，不覆盖已有文件。

## 安装与更新

无需 npm install 或构建。Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，打开「开发者模式」，点击「加载已解压的扩展程序」，选择本仓库目录 `D:\codes\SEO\SEO-Helper` 或安装包解压后的目录。

已安装旧版：替换文件，在扩展管理页点击 SEO Helper 的刷新按钮，再关闭并重新打开侧边栏。首次原生导出会申请下载权限，用于确认网站文件已下载完成。需要 Chrome 116+ 或支持 Side Panel 的新版 Edge。

## 使用

1. 在浏览器登录 SEM，打开关键词魔法工具，设置所需数据库及筛选条件。
2. 从「筛选模板」选择已保存的方案，或展开「编辑 / 保存筛选」并点击「读取当前页面链接」，也可粘贴完整链接。插件保留筛选参数，只替换词根 `q` 并清除分页 `page`。内置初始筛选来自最早提供的链接；更改网站条件后请重新读取链接。
3. 展开「从词根库选择」，勾选词根并点击「加入待研究」，每 5 个自动组成一批。也可展开「批量粘贴 / 编辑词根」，每行输入一批，行内用逗号分隔词根，点击「完成编辑」。例如第一行 `checker, calculator, converter`、第二行 `translator, ai writer`，列表会显示两批，分别包含 3 个和 2 个词根。`ai writer` 等含空格的词组保持完整。
4. 点击列表中的一行，高亮选择本批。展开底部「导出设置」，选择格式及子文件夹，再点击「导出本批」。插件复用一个研究标签页，按该行内的词根逐个点击网站原生导出，选中词表范围「所有」并点击指定格式。文件下载完成或确认当前筛选下无结果后，继续下一个词根，不必先运行预览。完成后可点击「下一批」。
5. 要导出目前浏览器页面的词表，点击「原生导出当前页」。此操作使用当前网页的查询和筛选，不重新导航。也可展开某个词根，单独点击「原生导出」。
6. 要同时浏览本批结果，点击「打开本批」。下方「本批词根结果」仍可展开某个词根，单独打开、读取预览或再次导出。预览只覆盖已加载行，原生导出文件由网站生成。

网站菜单包含「所有 / 此分组 / 已选定」和三种格式；插件选「所有」，保持网站已有的「保持分组」设置。格式和范围依据提供的实际菜单截图，[Semrush 官方说明](https://www.semrush.com/kb/617-keyword-magic-tool-manual)也介绍了该导出入口。实际行数和可用格式受网站当前筛选与账号导出额度影响。

## 筛选模板

1. 在 SEM 设置好条件，展开「编辑 / 保存筛选」，读取当前页面链接或粘贴完整链接。
2. 填写模板名称（例如 `美国 · 高搜索量低难度`），点击「保存模板」。可保存多个模板，名称最长 60 个字符。
3. 下次在上方「筛选模板」下拉框选择即可应用，下方显示当前数据库和筛选摘要。重开侧栏会恢复上次使用的模板及条件。

模板保存链接中的数据库、匹配方式和完整筛选参数；任务会继续使用当前批次的词根，下载格式和文件夹沿用当前设置。分页和临时网关参数不写入模板。

选择模板后更改链接，原模板不会自动覆盖。保留原名称时按钮显示「更新模板」，点击才会更新；换一个名称则保存为新模板。名称不区分大小写。旁边「删除」按钮移除选中模板，当前已应用的筛选仍可继续使用。

模板保存在当前浏览器的 `chrome.storage.local`，重启浏览器仍保留；不自动跨设备同步，卸载扩展会删除。切换模板不访问网站，之后打开或导出本批时使用选中的条件。

## 预制与自定义词根库

- 内置用户提供的 **51 个词根**，按原表顺序保留中文含义及常见搭配。`Sender / Receiver`、`Sample / Template`、`Scheme / Pattern`、`Checker / Detector` 已拆为独立词根；`Convert` 和 `Converter` 分别保留。
- 搜索可匹配英文词根、中文含义或搭配。可以跨搜索结果勾选；「全选结果」勾选当前匹配项，「取消选择」清除所有勾选。
- 「加入待研究」按词库顺序追加选中的词根，每 5 个一批，末尾不足 5 个独立成批，并跳过已在待研究列表中的同名词根。空列表加入全部预制词根会生成 **11 批**。待研究列表总计最多 200 个词根。
- 在「添加自己的词根」中输入词根，多个用逗号分隔，点击「添加」。同名词根不重复加入，含空格的词组保持完整；新增条目自动勾选，可继续加入研究。
- 每条旁边的「删除」移除词库条目，预制和自定义词根都可删除。它不移除已经加入待研究的批次；研究列表可在「批量粘贴 / 编辑词根」中修改。
- 词库保存在本机；重开后保留自定义条目及删除结果。升级旧版时初始化预制词库，已有筛选模板和研究批次继续使用。删除所有词库条目后不会自动重新填入预制数据。

## 每行一批

- 编号从 **1** 开始，每行是独立的一批。行内支持中英文逗号或分号，自动去重；空行忽略，总计最多 200 个词根，每个词根最长 150 个字符。
- 默认选择第一批；点击行文字或「上一批 / 下一批」切换，当前批次会保存在本机。按钮只打开或导出高亮行内的词根。
- 「打开本批」为该行每个词根新建一个后台 SEM 标签页，沿用相同筛选条件。导出仍是每个词根一个网站原生文件。
- 每行右侧显示已处理数量 / 本批词根数，包含成功下载和已确认无结果的词根；存在空结果时单独标注数量。下方结果区分别统计「已导出」与「无结果」。不同批次进度独立，即使两批含相同词根，也可分别处理。单个词根的「原生导出」可重复检查或下载。
- 升级旧版会保留原有换行、筛选、下载设置及对应记录；旧版曾将逗号转成换行的数据，可在编辑框内重新合并为想要的批次。

## 编辑和替换批次

点击列表下方「清空待研究」，确认后移除全部批次及预览、导出记录，保留筛选模板、词根库、导出设置和已下载文件。也可在「批量粘贴 / 编辑词根」中直接增加、删除或替换行。删除一行会清理对应的插件记录；改变某行的词根内容会作为新批次处理，只调整不同行的顺序则保留进度。

导出记录跨天保留，不会自动过期。第二天要重新导出同一批，点击结果区的「清除本批记录」并确认，再点击「导出本批」。此操作清除本批在当前筛选下的预览、导出和无结果标记，保留词根、其他批次的进度和已下载文件。任务运行期间不能清理。

运行任务时不能编辑或切换批次；底部「导出本批」会变为「停止任务」，点击即可停止后续工作。保存失败时保留上次列表和记录，在底部显示错误。

## 指定保存文件夹

- 在「导出子文件夹」填写 `SEO-Helper/项目A`，文件会自动保存在 **浏览器下载目录 / SEO-Helper / 项目A**，缺少的子文件夹自动创建。支持中文、空格、多层目录及 Windows 反斜杠；留空则直接保存到浏览器下载目录。
- 要直接保存到 `D:\SEO` 等完整磁盘路径，点击插件的「更改下载位置」，在浏览器下载设置中把「位置」改为 `D:\SEO`，然后将插件「导出子文件夹」留空。若填写 `项目A`，则保存到 `D:\SEO\项目A`。浏览器下载位置是全局设置，会影响其他网站下载。
- 若希望每次弹窗选位置，在同一个浏览器设置页开启「下载前询问每个文件的保存位置」。批量导出会等待你完成保存，每个文件最多等待 120 秒；最终以浏览器保存对话框中的位置为准。
- 文件夹设置会自动记住；导出后展开词根，可看到实际保存路径并点击「打开所在文件夹」。更改子文件夹后再次批量导出，会重新下载到新目录，不会因旧目录已有记录而跳过。

Chrome 的原生下载接口只允许建议下载目录内的相对路径，不能直接传入 `D:\SEO` 或 `..`。插件通过 `onDeterminingFilename` 给本次 SEM 原生文件指定子目录，不读取、重建或再次请求文件内容；其他网站下载不受插件的子文件夹设置影响。参见 [Chrome 下载路径规则](https://developer.chrome.com/docs/extensions/reference/api/downloads#type-FilenameSuggestion)。如果保存对话框或其他下载扩展改变了位置，请以结果中显示的实际路径为准。

## 任务与文件

- **v0.8.1：无结果时自动继续。** 页面明确显示「未找到任何数据」等空结果提示，且筛选提示或零数量能佐证时，插件等待页面状态稳定后标记「无结果」，跳过下载并继续下一词根。整批都无结果也会正常结束，不生成空文件，不修改网站筛选条件。原生导出当前页和单词预览也支持空结果。
- 无结果记录随当前批次与查询条件保存在本机，重开侧栏或再次导出本批会跳过已确认的空结果；改变筛选条件会重新检查。改变格式或文件夹不会重查空结果。要在相同条件下刷新，展开该词根点击「原生导出」；若新预览读到数据，旧的无结果导出标记也会清除。
- 禁用的导出按钮、空白表格、侧边分组无结果或页面加载中，均不会单独当作无结果。登录、验证、加载异常或未知页面仍会报错或等待超时，保留重试机会。页面稳定依赖 DOM 提示和等待时间；网站改版或长时间未显示加载标记时，可能需要人工复核。
- 任务运行时保持侧边栏打开，不要更改研究标签页的查询。批量导出串行执行；请勿在其他 SEM 标签页同时导出，以免同源下载无法区分。
- 已完成的文件由浏览器保存。插件记录词根、来源链接、格式、子文件夹、实际文件路径和下载完成时间，不修改、合并或重新生成文件内容。
- 同一批内再次点击「导出本批」，会跳过当前筛选、格式和子文件夹下已成功的词根。要重新下载，展开对应词根点击「原生导出」，或删除该行并完成编辑后再添加。改变浏览器的全局下载位置不会自动重置插件已有的导出记录。
- 点击停止或关闭侧边栏会停止后续任务；浏览器已经开始的下载可能继续。重新运行前先检查下载记录，避免重复文件。
- 网站导出菜单不可用、无法确认「所有」、下载中断或未确认完成时，会停止并给出说明。每次下载最多等待 120 秒；若出现浏览器保存对话框，需要完成保存。不要把超时提示当作文件一定没下载。
- 浏览器若询问是否允许该网站下载多个文件，需要先在浏览器中允许，批量下载才能继续。
- 原生导出独立于预览表格识别；即使页面表格结构暂时无法解析，只要原生导出控件可识别，仍可导出。若只有图标且无法定位按钮，可以先在网页手动打开「导出数据」菜单，再用「原生导出当前页」。

## 权限与存储

`https://trends.google.com/*` 与 `https://translate.googleapis.com/*` 为插件安装时声明的必需域名权限，用于自动读取探索页已渲染的查询、显示按钮，并将当前显示的外文查询交给 Google 翻译。无需点击功能启动按钮或在运行时申请这两个可选域名权限；浏览器自身的安装 / 更新授权仍需遵守。后台校验消息来源，仅接受顶层探索页的操作。点击对比才将关键词通过新版 URL 交给 Google Trends；不申请额外下载权限、不读取其他网站页面、不自动遍历词组。

词义分析不增加扩展权限，不抓取搜索结果或读取网站账号。内嵌页面在隔离框架中运行，查询时将当前关键词发给所选网站；Time / Geo 同时发送时间和地区。Ahrefs 只有点击「跳转」才打开网站，只有点击「复制关键词」才写入剪贴板。

使用 `sidePanel`、`storage`、`activeTab`、`scripting`，按需申请 `https://sem.3ue.co/*` 及 `downloads`。下载监听仅在导出任务期间工作，筛选点击后产生、来源为 SEM 且格式匹配的新下载，为该文件设置子目录并读取完成状态。点击「打开所在文件夹」时只查询对应的下载 ID，不扫描已有下载历史。Chrome 下载事件没有来源标签页 ID，因此使用串行任务、来源、格式和可用的 referrer 查询信息进行匹配。请只在一个侧边栏运行导出任务。

没有服务器、AI API、Cookie 读取、遥测或自动上传。配置、筛选模板、词根库、预览和导出进度保存在 `chrome.storage.local`。临时网关参数 `__gmitm` 不保存在研究链接中；请使用浏览器的正常登录状态。卸载会删除插件本机进度、模板和词库，已下载文件不受影响。
